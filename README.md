```md
# InternetY

Site institucional da InternetY voltado para serviços de:

- Data Management
- Business Intelligence
- Hosting

---

# Estrutura do Projeto

## index.html
Arquivo principal do site.

Responsável por:
- estrutura da página
- textos e conteúdos
- links
- layout geral

---

## internety.ico
Ícone (favicon) utilizado no navegador.

Exibido:
- na aba do navegador
- favoritos
- atalhos

---

## logoY.png
Logotipo principal da InternetY.

Utilizado:
- no cabeçalho
- identidade visual do site

---

## web.config
Arquivo de configuração do IIS.

Responsável por:
- redirecionamento HTTP → HTTPS
- regras do servidor
- configuração do site no IIS

---

# Tecnologias Utilizadas

- HTML5
- CSS3
- IIS
- GitHub

---

# Hospedagem

Projeto hospedado em VPS Windows utilizando IIS.

---

# Observações

- O site utiliza HTTPS.
- O arquivo `web.config` realiza o redirecionamento automático.
- O favicon está configurado através do arquivo `.ico`.

```
